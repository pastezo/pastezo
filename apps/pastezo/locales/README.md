# Переводы

Один файл на язык: `<BCP 47 тег>.json` (`ru.json`, `pt-BR.json`, `zh-Hant.json`, `sr-Latn.json`).
Эталон — `en.json`. Синтаксис — [ICU MessageFormat](https://unicode-org.github.io/icu/userguide/format_parse/messages/),
его понимают Crowdin, Lokalise, Phrase и т. п.

- `{app}`, `{day}` … — подстановки, переводить нельзя, можно переставлять.
- `<b>…</b>` — выделение (жирный); тег сохранить, текст внутри — перевести.
- Множественное число: `{count, plural, one {# запись} few {# записи} many {# записей} other {# записи}}`.

## Добавить язык

1. Скопировать `en.json` в `<тег>.json`, перевести.
2. Если язык пишется справа налево — добавить базовый код в `RTL` в `src/i18n.rs`.
3. Особые правила выбора (как `zh` → `zh-Hans`/`zh-Hant`) — в `resolve_language` там же.
4. `cargo test -p pastezo` — проверит ключи, подстановки, теги и синтаксис всех файлов.
| `settings.hotkey` | подпись слева в форме «Общие»: глобальное сочетание клавиш, открывающее Pastezo | с двоеточием по правилам языка |
| `settings.hotkeyRecord` | кнопка, когда сочетания нет: нажать и записать новое | глагол-действие, коротко |
| `settings.hotkeyTyping` | та же кнопка во время записи: ждём, пока нажмут сочетание | с многоточием, коротко |
| `settings.hotkeyClear` | кнопка рядом: убрать сочетание | глагол, одно слово |
| `settings.hotkeyHint` | пояснение мелким текстом под кнопкой | одно короткое предложение |
| `settings.hotkeyWayland` | то же место в сеансе Wayland (Linux), где кнопки нет: сочетание можно задать только в настройках системы | «Wayland» не переводить |
| `toast.hotkeyTaken` | уведомление-ошибка: система не дала сочетание, его заняло другое приложение | коротко |
| `toast.update` | уведомление при открытии окна: вышла новая версия | `{version}` — номер версии («0.2.0»); коротко, рядом кнопка `toast.download` |
| `toast.download` | кнопка в этом уведомлении: открывает страницу загрузки | глагол, одно слово |

## Поиск, даты и JSON

- `list.groupSimilar`: переключатель группировки загруженных записей; при текстовом поиске показываются все совпадения.
- `list.allDates`, `list.date`, `list.goDate`, `list.invalidDate`: выбор календарного дня; ввод `YYYY-MM-DD`.
- `list.variants`: число записей в раскрываемой группе, `{count}` включает первую запись.
- `json.tree`, `json.raw`: переключение дерева JSON и исходного текста.
- `json.invalid`: строка `{line}` и столбец `{column}` ошибки JSON.
- `json.limited`: достигнут предел отображаемых узлов; оригинал остаётся доступен.

Новые строки выше переведены на русский и английский; в остальных локалях пока используются английские строки.
